# 메모 예시

이 파일을 `notes/<날짜>.md`로 복사해 그날 있었던 일을 적어두면
`/daily-log`가 읽어서 초안을 만든다. 없으면 대화로 물어본다.

**자유 서식이다.** 형식을 맞추려 애쓸 필요 없다. 다만 한 줄에 한 사안씩,
**누가 / 무엇을 / 어떻게 했는지**가 들어가면 분류가 정확해진다.
사안 단위로 세므로 같은 주제로 여러 번 오갔어도 한 줄이면 된다.

기억나는 것만 적어도 된다. 없는 일을 채우는 것보다 빈 게 낫다.

---

```markdown
# 2026-07-31

- 김OO git push 인증 오류 → 원격 URL 재설정 안내
- 이OO 3일째 미접속 → DM, 내일 복귀 약속받음
- 미션2 진행 순서 문의 3명 → 선행 과제부터 하도록 순서 정리
- 4층 프로젝터 접촉 불량 → 운영팀 전달 필요
```

문체는 신경 쓰지 마라. `~했습니다` 체로 다듬는 건 초안 단계에서 한다.

터미널에서 `scripts/log.sh`로 한 번에 만들 때도 같은 형식이면 된다. 파일 대신
파이프로 넘겨도 되고(`echo "..." | scripts/log.sh`), 인자로 줘도 된다.
